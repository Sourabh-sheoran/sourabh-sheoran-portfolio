# Sourabh Sheoran — 3D Editorial Engineering Portfolio

A modern, high-performance **3D Editorial Developer Portfolio** designed with React, TypeScript, TailwindCSS, and Three.js. Features continuous realtime 360° 3D showcases, an interactive 3D Laptop with live simulated web app dashboards, an interactive iPhone showcase with live social feeds, automated GitHub repository synchronization, and a custom editorial design system.

🌐 **Live Website**: [https://sourabh-sheoran.github.io/sourabh-sheoran-portfolio/](https://sourabh-sheoran.github.io/sourabh-sheoran-portfolio/)

---

## 🌟 Key Highlights

- **Dynamic GitHub Auto-Sync**: Automatically fetches and synchronizes public repositories from [@Sourabh-sheoran](https://github.com/Sourabh-sheoran) via GitHub REST API with 5-minute intelligent caching and instant manual sync controls.
- **Continuous 360° 3D Hero Object**: WebGL / Three.js rotary showroom centerpiece with wireframe cage geometry, inner chrome core, and dynamic lighting.
- **Interactive 3D Laptop Visualizer**: Interactive laptop mockup running live simulated UI interfaces (WebSockets chat stream, telemetry radar, bio-pharma formulas, ATS score analyzers).
- **Interactive Dual Mobile iPhone Showcase**: Apple iPhone mockup featuring live work demonstrations and video reels for Instagram & LinkedIn.
- **Certifications & Achievements**: Interactive certificate carousel with direct credential verification links.
- **Integrated Contact & Direct Channels**: Connected with WhatsApp, Email, LinkedIn, Instagram, and GitHub.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: TailwindCSS, Vanilla CSS tokens, Glassmorphism
- **3D & Graphics**: Three.js, Lucide Icons, Canvas API
- **CI/CD**: GitHub Actions, GitHub Pages

## 🚀 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/Sourabh-sheoran/sourabh-sheoran-portfolio.git

# 2. Navigate into the directory
cd sourabh-sheoran-portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
